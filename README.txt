ACERVO LIVRE — Modelagem de Sites Básicos

ARQUIVOS
- index.html: estrutura da página
- css/style.css: estilos e responsividade
- img/: pasta reservada para imagens, caso queira adicionar capas próprias

COMO ABRIR
1. Extraia o arquivo ZIP.
2. Abra a pasta "acervo-livre" no VS Code.
3. Abra o arquivo index.html no navegador (ou use a extensão Live Server).

OBSERVAÇÕES
- O projeto usa HTML semântico e CSS próprio.
- O layout usa Flexbox e Grid e se adapta a telas menores.
- Busca, filtros e botões "Ver detalhes" são visuais, conforme o enunciado.
- Os nomes e sinopses dos livros são exemplos fictícios para o projeto.
- A fonte pode carregar da internet; o restante do layout funciona localmente.

ANTES DE ENTREGAR
- Confira se o professor exige seu nome, turma ou instituição no rodapé.
- Faça uma captura em 1366 px de largura e outra em 390 px de largura.
- Coloque as capturas na pasta do projeto antes de compactar novamente.
